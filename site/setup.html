Set up a server

Homespun Server keeps your originals and makes the compact copies. It runs on any always-on Mac, Linux computer, or NAS with room for your photos and videos.

Its source is on GitHub. On a Mac or Linux computer you build it with a few commands; on a NAS, it runs from a ready-made Docker image.

The Homespun app walks you through the same steps: tap Find My Home Computer. If there's no server on your Wi‑Fi yet, the app asks what you have at home and shows the steps for it. After the server is running, the app checks it and tells you if anything still needs installing.

On a Mac

A Mac that stays on, like a Mac mini, works well. A Mac also compresses Live Photos itself, so your iPhone only downloads the finished copies.

  1. Install Apple's developer tools (they include Swift and git; skip if Xcode is installed): 
    xcode-select --install
  2. Install Homebrew and ffmpeg (ffmpeg makes the smallest videos): 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install ffmpeg
  3. Download and build Homespun Server: 
    git clone https://github.com/akshob/homespun.git ~/homespun
cd ~/homespun && swift build -c release --product homespun-server
  4. Choose where originals are kept, and start the server. This installs it as ~/.local/bin/homespun-server, and it starts again whenever you log in: 
    ~/homespun/.build/release/homespun-server install-service --data ~/Pictures/Homespun
  5. Pair the app. Open Homespun on your iPhone, tap Find My Home Computer, choose your Mac, compare the same six-digit number on both screens, and click Allow on the Mac only if the numbers match. Then tap The Numbers Matched on the iPhone.

On Linux

  1. Install the packages Homespun needs (photo and video tools, SQLite, and Bonjour so the app can find the server). On Ubuntu or Debian: 
    sudo apt install -y git libvips-dev libsqlite3-dev ffmpeg avahi-utils
    Fedora: sudo dnf install -y git vips-devel sqlite-devel ffmpeg avahi-tools (enable RPM Fusion first for an ffmpeg with x265). Arch: sudo pacman -S --needed git libvips sqlite ffmpeg avahi.
  2. Install Swift with its installer, swiftly: 
    curl -fsSLO https://download.swift.org/swiftly/linux/swiftly-$(uname -m).tar.gz
tar zxf swiftly-$(uname -m).tar.gz && ./swiftly init --quiet-shell-followup
. ~/.local/share/swiftly/env.sh
  3. Download and build Homespun Server: 
    git clone https://github.com/akshob/homespun.git ~/homespun
cd ~/homespun && swift build -c release --product homespun-server
  4. Choose where originals are kept, and start the server. It runs as a systemd user service and starts with the computer: 
    ~/homespun/.build/release/homespun-server install-service --data ~/Pictures/Homespun
    This installs it as ~/.local/bin/homespun-server.
  5. Pair the app. This shows a QR code; scan it with your iPhone's camera, or tap the server in the app and enter the code: 
    ~/.local/bin/homespun-server pair

On a NAS, with Docker

The image ghcr.io/akshob/homespun-server runs on Synology, QNAP, UGREEN, TrueNAS, Unraid, Asustor, TerraMaster, or any Linux computer with Docker (amd64 and arm64). As with Linux, your iPhone compresses Live Photo motion.

  1. Make two folders as your own user (on Synology, in File Station): one for Homespun with a data folder in it, for example docker/homespun/data, and one for originals on your photos share, for example photo/Homespun.
  2. Add the settings file. Put compose.yaml in the Homespun folder. In it, set the originals folder, the name the app shows, and user to your user's IDs (run id in an SSH session on the NAS; on Synology the first user is usually 1026:100). The container never runs as root.
  3. Start it: docker compose up -d in the Homespun folder. On Synology: Container Manager › Project › Create, pick the Homespun folder, and use its compose.yaml.
  4. Pair the app. Open Homespun on your iPhone and tap Find My Home Computer, or show a QR code to scan: 
    docker exec homespun homespun-server pair
    In Container Manager, open the container's Terminal tab and run homespun-server pair.

Back up both folders. The data/tls folder holds the server's private encryption key; keep its backup private. To update, pull the new image and start it again; your data stays in the folders:

docker compose pull && docker compose up -d

Using Immich

If you already back up to Immich, Homespun Server can use the originals there instead of storing its own. In the app, open Server › Connect Immich and enter Immich's address and an API key. Create the key in Immich under Account Settings › API Keys with only the asset.read and asset.download permissions. Homespun never changes or deletes anything in Immich.

In the Immich app, exclude the Homespun album from backup so compact copies are not uploaded.

Your network

The app and server talk over an encrypted connection; the app checks the server's key every time. Keep the iPhone on the same Wi-Fi while Homespun works. Plain HTTP is not accepted. Codes work once, for 10 minutes after you run pair, or 2 minutes after the first pairing check.

Server Check shows the server key. Compare it with homespun-server certificate on the server, especially once after upgrading an existing pairing. See server identity help and proxy and Tailscale setup.
