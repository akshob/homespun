Support

Help with backing up, freeing up space, and getting originals back.

Report a problem

In the app, open Server › Help and About › Report a Problem. Say what happened; you can see the diagnostics that go with it before you send it, and you get a report number. You can also email support@homespun.photos. The reports you've sent are listed under Server › Help and About › Sent Reports.

Bugs and ideas are also welcome as GitHub issues. Found a security problem? Please report it privately on GitHub: Report a vulnerability.

Common questions

Will Homespun delete my photos?

Only if you ask it to, and only after your server has proven it holds an identical copy of the original. iOS asks you to confirm, and deleted items stay in Recently Deleted. Homespun never empties Recently Deleted.

Do I need a server?

Yes. Homespun Server runs on a Mac, a Linux computer, or a NAS you already have, keeps your originals at home, and makes the compact copies. If you use Immich, Homespun Server can work with the originals already there.

How do I set up a server?

See Set up a server, or tap Find My Home Computer in the app. A Mac, a Linux computer, or a NAS with Docker works.

Can't confirm this is your server

Homespun has stopped sending anything because the server's security key changed and it could not prove it still has this iPhone's pairing. This can happen after reinstalling without the data folder, restoring an incomplete backup, or if another device is pretending to be your server. Run homespun-server certificate on your server and compare its key with Server Check. Restore the complete data folder, or choose Pair Again and use a new QR code or pairing code. Never approve a Mac's request unless its six-digit number matches the iPhone, then confirm that match on the iPhone before pairing completes.

A replacement key that passes the pairing proof is confirmed automatically, with a notice. Certificates renew with the same key. Keep tls/ in your server backup. After upgrading an old pairing, compare the key once: a pairing token exposed before encryption was added could still impersonate it.

If your router gives the server a new address, Homespun looks for it with Bonjour and checks the same pinned key before following it. Server Check shows its current address and says when it found the server at a new one. Keep Bonjour enabled and allow Local Network access. Another server with the same name but a different key is not enough to move the pairing.

Update Homespun Server

The app needs Homespun Server 0.2 or later for encrypted connections. Rebuild and run install-service again, or pull and recreate the Docker container as in Set up a server. Update the app too: older builds cannot reach an HTTPS-only server. Existing pairings upgrade securely without pairing again.

Using a proxy or Tailscale

Use an HTTPS proxy with a publicly trusted certificate, and set HOMESPUN_PUBLIC_URL to its full HTTPS address. Its backend must also use HTTPS. For Tailscale, run tailscale serve --bg https+insecure://127.0.0.1:8787. Unverified proxy-to-server TLS must stay on loopback or a trusted private path. Direct IP addresses and .local names use key pinning. A qualified name pointing straight at the self-signed server is blocked by iOS's transport rules; use the IP address, a .local name, or a proxy with a trusted certificate instead.

Can I get an original back on my iPhone?

Yes. Open the item and choose Restore Original, or select several. Homespun downloads each original from your server, checks it, adds it to Photos with its favorite and albums, and only then removes the compact copy. When you free up space, you can also keep any original full size instead.

What does the purchase unlock?

Automatic Mode and widgets (Home Screen, Lock Screen, and Apple Watch), with one purchase on all your devices with your Apple Account. Family Sharing is included. Everything else is free. Turning on Automatic Mode or opening a locked widget asks for it; Restore Purchase is right there if you already bought it.

How small are the compact copies?

Photos fit within 2048 pixels on the long edge. Videos fit within 720p and use HEVC. Copies keep the date, place, favorite, and Live Photo motion. If a copy would not be smaller, Homespun keeps the original as is.

What does Homespun leave unchanged?

Some videos are kept as they are until their conversion has been tested: HDR in formats other than HLG, Dolby Vision without an HLG base, and video above 60 frames per second.
